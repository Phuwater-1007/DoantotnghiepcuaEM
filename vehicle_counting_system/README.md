# Vehicle Counting System

Tài liệu cài đặt, cấu hình và hướng dẫn sử dụng đầy đủ được duy trì tập trung tại [README của dự án](../README.md).

Chạy nhanh từ thư mục gốc sau khi đã hoàn tất cài đặt và tạo `vehicle_counting_system/.env`:

```powershell
.\.venv\Scripts\python.exe web_main.py
```

Kiểm thử:

```powershell
.\.venv\Scripts\python.exe -m pytest vehicle_counting_system\tests -q
```

Không bổ sung hướng dẫn riêng vào file này để tránh sai lệch đường dẫn, tài khoản hoặc cách chạy so với tài liệu chính.
